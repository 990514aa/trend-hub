# 🔥 TrendHub — SNS 트렌드 통합 대시보드

유튜브 · 쇼츠 · 틱톡 · 스레드 · X(트위터)의 핫토픽/최신 트렌드/최다 조회 콘텐츠를 **한 화면**에서 보는 웹사이트.

- ✅ **플랫폼 로그인 불필요** — 어떤 SNS 계정도 연결하지 않음
- ✅ **API 키 발급 불필요** — 공개 데이터(RSS·공개 페이지·공개 엔드포인트)만 수집
- ✅ **외부 npm 패키지 0개** — Node.js 내장 모듈만 사용 (`npm install` 필요 없음)
- ✅ **실시간 공유** — 방문자가 올린 핫 콘텐츠가 모든 접속자 화면에 즉시 반영 (SSE)
- ✅ **자동 갱신** — 10분마다 트렌드 재수집 + 접속자 전원에게 실시간 푸시

## 실행

```bash
node server.js
# → http://localhost:4173
```

Node.js 18 이상만 있으면 됩니다.

## 데이터 소스 (모두 무키·무로그인)

| 섹션 | 소스 | 내용 |
|---|---|---|
| 🔍 핫토픽 | Google Trends 공식 RSS | 실시간 급상승 검색어 + 관련 뉴스 |
| ▶ 유튜브 | 유튜브 내부 검색 API (페이지에 공개된 엔드포인트) | 핫토픽 키워드 × 이번 주 조회수순 인기 영상 |
| ⚡ 쇼츠 | 〃 (4분 미만 + shorts 필터) | 핫토픽 관련 인기 쇼츠 |
| 🎵 틱톡 | tikwm 공개 피드 | 인기 영상 (재생수·좋아요) |
| 𝕏 트렌드 | trends24.in | 대한민국 실시간 트렌드 |
| @ 스레드 | (공개 트렌드 API 없음) | 핫키워드 → 스레드 검색 링크 + 공유 게시판 |

> 참고: 유튜브는 2025년에 '인기 급상승' 페이지를 폐지해서, 핫토픽 키워드 기반
> "이번 주 조회수순" 검색으로 실제 많이 본 영상을 모으는 방식을 사용합니다.

## 🧊 3D 해부도 (분해도 · X-ray · 단면도)

헤더의 **🧊 3D 해부도** 버튼을 누르면 6개 트렌드 섹션이 적층 기판처럼 3D로 쌓인 화면이 열립니다.
외부 3D 라이브러리 없이 CSS 3D transform + clip-path 로만 구현했습니다 (의존성 0개 원칙 유지).

| 모드 | 무엇을 보여주나 |
|---|---|
| 🧱 조립 | 6개 섹션을 두께 있는 한 덩어리로 — 옆면 색으로 플랫폼 구분 |
| 💥 분해도 (exploded view) | 레이어를 Z축으로 벌리고 지시선 + 콜아웃 라벨로 각 섹션의 출처·수집 건수 표시 |
| 🩻 X-ray | 판을 반투명 와이어프레임으로 투시 — 평소 감춰둔 계측값(소스, 항목 수, 수집 상태, 지역)이 드러남 |
| 🔪 단면도 (cutaway) | 위쪽 레이어를 L자로 잘라내고 해칭 단면을 그려 아래 레이어 내부를 노출 |

- 드래그 회전 / 휠·핀치 확대 / 레이어 탭 시 단독 보기, 자동 회전 토글
- 단축키: `1` `2` `3` 모드 · `X` 투시 · `Space` 자동회전 · `R` 시점 초기화 · `Esc` 닫기
- 회전·분해 상태에 맞춰 배율과 위치를 자동 보정하므로 화면 밖으로 잘리지 않습니다
- 데이터는 메인 화면과 같은 SSE 스트림을 구독해 열어둔 채로도 실시간 갱신됩니다

## 실시간 공유 게시판

하단 게시판에 닉네임·플랫폼·제목·링크를 올리면 **접속 중인 모든 사람에게 즉시** 나타납니다.
글은 `data/posts.json`에 저장되어 서버를 재시작해도 유지됩니다 (최근 200개).

## 남들도 보게 하기 (배포/공유)

**① 즉석 공유 (설치 1개, 계정 불필요)** — Cloudflare 터널:

```bash
brew install cloudflared
node server.js &
cloudflared tunnel --url http://localhost:4173
# 출력되는 https://xxxx.trycloudflare.com 주소를 아무에게나 공유
```

**② 상시 배포 (무료 티어)** — Render / Railway / Fly.io 등 Node 호스팅에 이 폴더를 올리면 끝.
시작 명령은 `node server.js`, 포트는 `PORT` 환경변수를 자동으로 따릅니다.
(Render 기준: New Web Service → 이 저장소 연결 → Start Command `node server.js`)

**③ 같은 와이파이에서** — `http://<내 맥의 IP>:4173` 으로 바로 접속 가능.

## 한계 (정직하게)

- 비공식 공개 소스를 파싱하므로, 플랫폼이 구조를 바꾸면 해당 섹션이 일시적으로 비어질 수 있습니다.
  그 경우 카드에 오류 메시지가 뜨고 다음 주기에 자동 재시도합니다.
- 스레드는 로그인 없는 트렌드 소스가 존재하지 않아 검색 링크 + 커뮤니티 공유로 대체했습니다.
- 공유 게시판은 인증이 없는 열린 게시판입니다. 공개 배포 시 스팸이 걱정되면
  `server.js`의 POST 핸들러에 IP당 속도 제한을 추가하는 것을 권장합니다.
