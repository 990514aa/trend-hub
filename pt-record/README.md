# 물리치료 기록 자동화

치료실 베드별 **치료 시작·종료 시각을 자동으로 기록**하고, 종료 알람을 울리며, **EMR에 붙여넣을 치료기록문**을 자동으로 만들어 주는 프로그램입니다.
여러 PC·태블릿에서 같은 화면을 함께 씁니다. 설치 방식은 두 가지입니다.

| 방식 | 설명 |
|---|---|
| **① 메인 PC 프로그램 (권장)** | 메인 PC에서 `물리치료기록.exe` 실행 → 다른 PC·태블릿은 같은 와이파이에서 접속. 구글 설정 불필요, 인터넷 끊겨도 동작. 데이터 폴더를 구글 드라이브 폴더로 지정하면 자동 백업. → **아래 0장** |
| ② 구글 스프레드시트 | 구글 Apps Script 웹앱. 메인 PC 없이 어디서든 접속(인터넷 필요). → 1장 |

- 물리치료실(베드 12): 표층열치료 — 적외선 열치료(IR)로 시행, 간섭파(ICT), 콜드팩, 냉동치료(Cryo), 저출력레이저, 경추·골반 견인 (TENS는 설정에서 켜기)
- 물리치료실은 12베드(1~10번 위쪽 벽, 11·12번 휴게실 옆). 운동·특수치료실(단순운동, 복합운동, 도수치료, 체외충격파)은 배치도 아래에 특1~특4로 표시 (베드 수는 설정에서 변경)
- 첫 화면은 **치료실 배치도** — 위쪽 벽 1~10번(2개씩), 아래 스테이션·출입구·11·12번·휴게실. 빈 베드를 누르면 치료 시작, 치료 중인 베드를 누르면 메뉴(종료·연장·기록·취소)
- 환자는 **등록번호 + 이름** 으로 관리

## 0. 메인 PC 프로그램 설치 (권장)

1. `물리치료기록.zip` 을 **[압축 풀기]** 로 메인 PC(스테이션 PC)의 `C:\물리치료기록` 같은 곳에 풀고 `물리치료기록.exe` 더블클릭 (zip 안에서 바로 실행하지 않기)
   - "Windows의 PC 보호" → `추가 정보` → `실행` (서명 없는 병원 자체 프로그램이라 뜨는 안내)
   - "Windows 방화벽" → `개인 네트워크` 체크 → `액세스 허용` (태블릿 접속에 필요)
2. 검은 창(서버)이 뜨고 브라우저에 화면이 열립니다. **검은 창은 닫지 말고 최소화.**
3. 앱 [설정] → **메인 PC 연결**: 태블릿 접속 주소 확인, **접속 PIN** 지정, **데이터 폴더를 구글 드라이브 폴더로 변경**(예: `G:\내 드라이브\물리치료기록`, Google Drive 데스크톱 설치 필요)
4. 다른 PC·태블릿: 크롬에 그 주소(예: `http://192.168.0.10:8080`) 입력 → PIN 입력 → 즐겨찾기/홈 화면에 추가
5. 부팅 시 자동 실행: `Win+R` → `shell:startup` → exe 의 **바로 가기**를 넣기

기록·설정은 exe 위치와 무관하게 **`%APPDATA%\물리치료기록`** 에 저장되어 exe를 옮기거나 새 버전으로 바꿔도 이어집니다(이전 버전의 exe 옆 데이터는 첫 실행 때 자동 이전). 매일 `backups\날짜` 로 30일치 자동 백업, 저장할 때마다 직전 파일을 `.bak` 으로 보관하고 손상 시 자동 복구합니다.

자세한 내용은 zip 안의 `사용방법.txt`. 데이터 폴더 구성: `records/YYYY-MM.json`(기록), `patients.json`, `settings.json`, `audit/`(수정 이력), `기록_YYYY-MM.csv`(엑셀용 월별 대장, 자동 갱신).

빌드: `server/build-exe.sh` (Node.js 단일 실행 파일). 개발 중에는 `node server/server.js` 로 바로 실행.

## 1. 구글 스프레드시트 방식 설치 (처음 한 번, 약 10분)

> 병원 **공용 구글 계정**(예: 치료실 전용 계정)으로 진행하세요. 모든 기기가 이 계정으로 로그인해서 사용합니다.

1. **구글 드라이브** → `새로 만들기` → `Google 스프레드시트` → 이름을 `물리치료 기록`으로 바꿉니다.
2. 스프레드시트 메뉴 `확장 프로그램` → `Apps Script` 를 엽니다.
3. 왼쪽 `Code.gs` 의 기존 내용을 모두 지우고, 이 폴더의 **`Code.gs`** 내용을 붙여넣습니다.
4. 왼쪽 파일 목록의 `＋` → `HTML` → 이름을 **`Index`** 로 입력(확장자 없이) → 이 폴더의 **`Index.html`** 내용을 붙여넣습니다.
5. 왼쪽 톱니바퀴 `프로젝트 설정` → **"편집기에서 'appsscript.json' 매니페스트 파일 표시"** 를 체크합니다. 그러면 편집기에 `appsscript.json` 이 보입니다. 그 내용을 이 폴더의 **`appsscript.json`** 으로 바꿉니다. (시간대 `Asia/Seoul`, 웹앱 접근 권한 `나만` 설정)
6. 상단 💾 저장 → 함수 선택 칸에서 **`setup`** 을 고르고 `▶ 실행` 을 누릅니다.
   - "승인 필요" 창이 뜨면 → 계정 선택 → `고급` → `물리치료 기록(으)로 이동` → `허용`
   - 스프레드시트에 `환자`, `설정`, `수정이력`, `기록_2026-09` 탭이 생기면 성공입니다.
7. 오른쪽 위 `배포` → `새 배포` → 톱니바퀴에서 **웹 앱** 선택
   - 실행 계정: **나**
   - 액세스 권한이 있는 사용자: **나만**
   - `배포` → 나오는 **웹 앱 URL** 을 복사합니다.
8. 치료실 PC·태블릿마다 같은 공용 계정으로 크롬에 로그인하고, 그 URL을 즐겨찾기(태블릿은 `홈 화면에 추가`)해 둡니다.
9. 앱의 **[설정]** 탭에서:
   - 기기 이름 입력 (예: `물리치료실 PC1`, `운동치료실 태블릿`) → 수정 이력에 표시됩니다.
   - **처방의·치료사 명단** 입력
   - **치료 항목의 코드·급여구분·기본시간**을 병원 수가표와 맞춥니다 (특히 도수·충격파·Cryo).

### 프로그램을 고친 뒤 다시 반영하려면
Apps Script 에서 코드를 바꾼 뒤 `배포` → `배포 관리` → ✏️ 편집 → 버전 `새 버전` → `배포`. URL은 그대로입니다.

### 설치 없이 먼저 써 보기
`Index.html` 파일을 PC에서 더블클릭해 크롬으로 열면 **이 기기 단독 모드**로 동작합니다. 기록은 그 브라우저에만 저장되고, 다른 기기와 공유되지 않습니다. [설정] → `데이터 백업`으로 파일을 저장할 수 있습니다.

## 2. 하루 사용 흐름

| 단계 | 하는 일 | 자동으로 되는 것 |
|---|---|---|
| 접수 | `접수명단 붙여넣기`에 EMR 접수 목록 붙여넣기 (한 줄에 `등록번호 이름`) | 대기 환자 목록 생성 |
| 시작 | 대기 환자 → 빈 베드 클릭 (또는 빈 베드 → 등록번호 입력) → `치료 시작` | **시작 시각 기록**, 지난 처방(치료 조합·시간·강도·부위) 자동 불러오기 |
| 진행 | 베드 카드에서 남은 시간 확인 | 1분 전 노란색, **종료 시 알람음 + 음성 안내("3번 베드 치료 종료")**, 초과 시 빨간색 깜빡임 |
| 종료 | `종료` (순차 치료는 `다음 단계`) | **종료 시각 기록**, 기록 작성 창 열림 |
| 기록 | 치료 전·후 상태는 고정 문구('통증 및 부종 호소' / '통증 경감 및 부종 감소', [설정]에서 변경)로 자동 입력 — 확인만 하고 → `작성 완료 + 복사` | **완료 확인 창**(부족한 사항이 있으면 목록을 보여주고 제출 여부 확인) → EMR 기록문 생성 + 클립보드 복사 |
| EMR | EMR에 붙여넣기 → `EMR에 입력 완료` 체크 | 치료 대장에 EMR✓ 표시 |

- **동시/이어서 진행**: IR·ICT 등은 동시에, 레이저는 IR·ICT가 끝나면 **자동으로 이어서** 시작됩니다(알림만 울림, 버튼 불필요). 단순운동은 시작 창에서 '끝나고 이어서 / 먼저(선행)'를 고릅니다. 버튼은 [종료] 하나입니다.
- **빠른 선택 직접 만들기**: [설정] → 빠른 선택에서 치료실별로 추가·수정·삭제·순서 변경(치료 항목·시간·단순운동 순서 포함). 치료 시작 창의 [＋ 지금 선택 저장]으로도 추가. [기본 목록으로 되돌리기] 가능.
- **찜(준비 중)**: 빈 베드의 [찜]을 누르면 슬립을 쓰는 동안 다른 기기에서 그 베드를 쓰지 못하게 주황색으로 표시됩니다.
- **베드 이동**: 치료 중인 베드를 **끌어서 빈 베드에 놓거나**(태블릿은 길게 누른 뒤 끌기), 베드 메뉴에서 빈 베드를 고릅니다(시각·기록 유지). 치료 중·준비 중 베드에 놓으면 이동 불가 안내가 뜹니다. 대기 환자를 빈 베드에 끌어 놓으면 치료 시작 창이 열립니다.
- **보험 구분**: 건강보험·자보·산재·일반. 자보는 두 부위 동시 시행으로 기록되고, 건강보험 산정 경고는 생략됩니다. 접수명단 줄에 '자보'·'산재'가 있으면 자동 표시됩니다.
- **부위 1차·2차**: 접수명단(대기 환자)의 [부위]에서 1차로 정하고(재진은 지난 부위 자동), 못 정한 사람은 치료 시작 창에서 정합니다.
- **자동 멈춤 장비**(적외선·ICT·TENS·레이저·견인·충격파): 설정 시간이 지나 장비가 멈춘 경우, 종료 버튼을 늦게 눌러도 **실제 장비 종료 시각**(시작+설정시간)으로 기록됩니다. 콜드팩·Cryo 는 버튼을 누른 실제 시각으로 기록됩니다.
- **작성 대기**: 종료했지만 기록을 쓰지 않은 건은 오른쪽 `작성 대기`에 남습니다. 최근 7일까지 표시됩니다.
- **치료 대장**: 날짜별 전체 목록, 여러 건 기록문 한꺼번에 복사, **선택 삭제**(사유 입력, 수정 이력에 남음), 엑셀(CSV) 내보내기, 인쇄.
- **환자 기록**: 등록번호·이름으로 검색하면 그 환자의 모든 치료기록문을 날짜순으로 보고 인쇄·복사할 수 있습니다. 환자 메모(예: "열 민감")는 치료 시작 때 표시됩니다.

## 3. 기록 기준

기록문은 첨부 샘플의 **물리치료기록지 기재사항**을 따릅니다.
① 치료 전 상태 ② 처방의·시행자 ③ 치료 부위·방법 ④ 치료시간·강도 ⑤ 치료 후 상태·경과
이 중 하나라도 비어 있으면 `작성 완료`가 되지 않습니다. 항목별 코드·강도 기록 항목·산정기준은 앱의 **[산정·강도 기준]** 탭에 정리돼 있습니다.

프로그램이 경고하는 산정기준:
- 표층열 + 한냉치료 같은 날 → 한 가지만 산정
- 표층열·한냉·ICT·TENS → 외래 1일 1회, 입원 1일 2회
- 단순운동 10분 미만, 복합운동 30분 미만 → 산정 불가
- 단순운동 + 복합운동 동시 → 주된 항목만 산정
- 레이저·견인 → 해당 전문의 상근·처방 요건 (기준 탭에 안내)

> ⚠️ 코드·산정기준은 심평원 고시를 인용한 공개 자료로 정리했으며 개정될 수 있습니다. 도수(KR006, 첨부 샘플 기준)·체외충격파(SZ084)·Cryo 는 병원 수가표로 꼭 확인하세요.
> 강도 기본값(핫팩 보관온도, ICT 주파수, 견인 중량 참고치 등)은 일반적인 임상 적용 범위입니다. **실제 처방·장비 설정값으로 고쳐서 기록**해야 합니다.
> 경과 문구 버튼은 입력을 돕는 용도입니다. 모든 환자에게 같은 문구를 쓰면 심사에서 형식적 기록으로 지적될 수 있으니, 환자 표현을 함께 적으세요.

## 4. 보안 · 개인정보

- 스프레드시트를 **다른 사람과 공유하지 마세요.** 웹앱은 공용 계정으로 로그인한 기기에서만 열립니다(액세스: 나만).
- 공용 계정에는 **2단계 인증**을 켜고, 퇴근 시 공용 PC 외의 기기는 로그아웃하세요.
- 저장 항목: 등록번호, 이름, 치료 내용. 주민번호·연락처는 저장하지 않습니다.
- 진료기록 원본은 EMR입니다. 이 시트는 치료실 업무 보조기록이며, 보존 기간·폐기는 병원 개인정보 관리 규정을 따르세요.
- 모든 생성·수정·삭제는 `수정이력` 탭에 **일시·기기·변경 내용**이 남습니다.
