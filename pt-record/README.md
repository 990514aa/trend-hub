# 물리치료 기록 자동화

치료실 베드별 **치료 시작·종료 시각을 자동으로 기록**하고, 종료 알람을 울리며, **EMR에 붙여넣을 치료기록문**을 자동으로 만들어 주는 프로그램입니다.
기록은 병원 구글 드라이브의 **구글 스프레드시트**에 저장되므로 여러 PC·태블릿에서 같은 화면을 함께 씁니다.

- 물리치료실(베드 12): 표층열(Hot pack), 간섭파(ICT), 콜드팩, 냉동치료(Cryo), 저출력레이저, 경추·골반 견인 (TENS는 설정에서 켜기)
- 운동·특수치료실: 단순운동, 복합운동, 도수치료, 체외충격파
- 환자는 **등록번호 + 이름** 으로 관리

---

## 1. 설치 (처음 한 번, 약 10분)

> 병원 **공용 구글 계정**(예: 치료실 전용 계정)으로 진행하세요. 모든 기기가 이 계정으로 로그인해서 사용합니다.

1. **구글 드라이브** → `새로 만들기` → `Google 스프레드시트` → 이름을 `물리치료 기록`으로 바꿉니다.
2. 스프레드시트 메뉴 `확장 프로그램` → `Apps Script` 를 엽니다.
3. 왼쪽 `Code.gs` 의 기존 내용을 모두 지우고, 이 폴더의 **`Code.gs`** 내용을 붙여넣습니다.
4. 왼쪽 파일 목록의 `＋` → `HTML` → 이름을 **`Index`** 로 입력(확장자 없이) → 이 폴더의 **`Index.html`** 내용을 붙여넣습니다.
5. 왼쪽 톱니바퀴 `프로젝트 설정` → **"편집기에서 'appsscript.json' 매니페스트 파일 표시"** 를 체크합니다. 그러면 편집기에 `appsscript.json` 이 보입니다. 그 내용을 이 폴더의 **`appsscript.json`** 으로 바꿉니다. (시간대 `Asia/Seoul`, 웹앱 접근 권한 `나만` 설정)
6. 상단 💾 저장 → 함수 선택 칸에서 **`setup`** 을 고르고 `▶ 실행` 을 누릅니다.
   - "승인 필요" 창이 뜨면 → 계정 선택 → `고급` → `물리치료 기록(으)로 이동` → `허용`
   - 스프레드시트에 `환자`, `설정`, `수정이력`, `기록_2026-09` 탭이 생기면 성공입니다.
7. 오른쪽 위 `배포` → `새 배포` → 톱니바퀴에서 **웹 앱** 선택
   - 실행 계정: **나**
   - 액세스 권한이 있는 사용자: **나만**
   - `배포` → 나오는 **웹 앱 URL** 을 복사합니다.
8. 치료실 PC·태블릿마다 같은 공용 계정으로 크롬에 로그인하고, 그 URL을 즐겨찾기(태블릿은 `홈 화면에 추가`)해 둡니다.
9. 앱의 **[설정]** 탭에서:
   - 기기 이름 입력 (예: `물리치료실 PC1`, `운동치료실 태블릿`) → 수정 이력에 표시됩니다.
   - **처방의·치료사 명단** 입력
   - **치료 항목의 코드·급여구분·기본시간**을 병원 수가표와 맞춥니다 (특히 도수·충격파·Cryo).

### 프로그램을 고친 뒤 다시 반영하려면
Apps Script 에서 코드를 바꾼 뒤 `배포` → `배포 관리` → ✏️ 편집 → 버전 `새 버전` → `배포`. URL은 그대로입니다.

### 설치 없이 먼저 써 보기
`Index.html` 파일을 PC에서 더블클릭해 크롬으로 열면 **이 기기 단독 모드**로 동작합니다. 기록은 그 브라우저에만 저장되고, 다른 기기와 공유되지 않습니다. [설정] → `데이터 백업`으로 파일을 저장할 수 있습니다.

## 2. 하루 사용 흐름

| 단계 | 하는 일 | 자동으로 되는 것 |
|---|---|---|
| 접수 | `접수명단 붙여넣기`에 EMR 접수 목록 붙여넣기 (한 줄에 `등록번호 이름`) | 대기 환자 목록 생성 |
| 시작 | 대기 환자 → 빈 베드 클릭 (또는 빈 베드 → 등록번호 입력) → `치료 시작` | **시작 시각 기록**, 지난 처방(치료 조합·시간·강도·부위) 자동 불러오기 |
| 진행 | 베드 카드에서 남은 시간 확인 | 1분 전 노란색, **종료 시 알람음 + 음성 안내("3번 베드 치료 종료")**, 초과 시 빨간색 깜빡임 |
| 종료 | `종료` (순차 치료는 `다음 단계`) | **종료 시각 기록**, 기록 작성 창 열림 |
| 기록 | 부위·치료 전/중/후 상태·NRS·강도 확인 → `작성 완료 + 복사` | **EMR 기록문 생성 + 클립보드 복사**, 필수항목·산정기준 점검 |
| EMR | EMR에 붙여넣기 → `EMR에 입력 완료` 체크 | 치료 대장에 EMR✓ 표시 |

- **동시/순차 치료**: 같은 '단계'의 항목은 동시에(예: HP+ICT 15분), 다음 단계는 앞 단계가 끝난 뒤(예: 레이저 5분) 진행됩니다. 시작 창에서 항목별 시간(10/15/20분)과 단계를 바꿀 수 있습니다.
- **자동 멈춤 장비**(ICT·TENS·레이저·견인·충격파): 설정 시간이 지나 장비가 멈춘 경우, 종료 버튼을 늦게 눌러도 **실제 장비 종료 시각**(시작+설정시간)으로 기록됩니다. 핫팩·콜드팩·Cryo 는 버튼을 누른 실제 시각으로 기록됩니다.
- **작성 대기**: 종료했지만 기록을 쓰지 않은 건은 오른쪽 `작성 대기`에 남습니다. 최근 7일까지 표시됩니다.
- **치료 대장**: 날짜별 전체 목록, 여러 건 기록문 한꺼번에 복사, 엑셀(CSV) 내보내기, 인쇄.
- **환자 기록**: 등록번호·이름으로 검색하면 그 환자의 모든 치료기록문을 날짜순으로 보고 인쇄·복사할 수 있습니다. 환자 메모(예: "열 민감")는 치료 시작 때 표시됩니다.

## 3. 기록 기준

기록문은 첨부 샘플의 **물리치료기록지 기재사항**을 따릅니다.
① 치료 전 상태 ② 처방의·시행자 ③ 치료 부위·방법 ④ 치료시간·강도 ⑤ 치료 후 상태·경과
이 중 하나라도 비어 있으면 `작성 완료`가 되지 않습니다. 항목별 코드·강도 기록 항목·산정기준은 앱의 **[산정·강도 기준]** 탭에 정리돼 있습니다.

프로그램이 경고하는 산정기준:
- 표층열 + 한냉치료 같은 날 → 한 가지만 산정
- 표층열·한냉·ICT·TENS → 외래 1일 1회, 입원 1일 2회
- 단순운동 10분 미만, 복합운동 30분 미만 → 산정 불가
- 단순운동 + 복합운동 동시 → 주된 항목만 산정
- 레이저·견인 → 해당 전문의 상근·처방 요건 (기준 탭에 안내)

> ⚠️ 코드·산정기준은 심평원 고시를 인용한 공개 자료로 정리했으며 개정될 수 있습니다. 도수(KR006, 첨부 샘플 기준)·체외충격파(SZ084)·Cryo 는 병원 수가표로 꼭 확인하세요.
> 강도 기본값(핫팩 보관온도, ICT 주파수, 견인 중량 참고치 등)은 일반적인 임상 적용 범위입니다. **실제 처방·장비 설정값으로 고쳐서 기록**해야 합니다.
> 경과 문구 버튼은 입력을 돕는 용도입니다. 모든 환자에게 같은 문구를 쓰면 심사에서 형식적 기록으로 지적될 수 있으니, NRS 변화와 환자 표현을 함께 적으세요.

## 4. 보안 · 개인정보

- 스프레드시트를 **다른 사람과 공유하지 마세요.** 웹앱은 공용 계정으로 로그인한 기기에서만 열립니다(액세스: 나만).
- 공용 계정에는 **2단계 인증**을 켜고, 퇴근 시 공용 PC 외의 기기는 로그아웃하세요.
- 저장 항목: 등록번호, 이름, 치료 내용. 주민번호·연락처는 저장하지 않습니다.
- 진료기록 원본은 EMR입니다. 이 시트는 치료실 업무 보조기록이며, 보존 기간·폐기는 병원 개인정보 관리 규정을 따르세요.
- 모든 생성·수정·삭제는 `수정이력` 탭에 **일시·기기·변경 내용**이 남습니다.

## 5. 스프레드시트 구성

| 탭 | 내용 |
|---|---|
| `기록_YYYY-MM` | 월별 치료 기록. 날짜·등록번호·이름·치료항목·시작·종료·소요시간·처방의·시행자·상태·EMR 기록문 (마지막 `DATA` 열은 프로그램용 — 직접 수정 금지) |
| `환자` | 등록번호·이름·메모·최근 처방 |
| `설정` | 앱 설정 (앱의 [설정] 탭에서 변경) |
| `수정이력` | 생성·수정·삭제 이력 |

## 파일

| 파일 | 설명 |
|---|---|

| `Code.gs` | 구글 스프레드시트 저장 서버 (Apps Script) |
