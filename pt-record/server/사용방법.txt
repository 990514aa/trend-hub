물리치료 기록 — 메인 PC 프로그램 사용 방법
==============================================

※ 화면 사진이 있는 자세한 사용법은 같은 폴더의 "사용안내(튜토리얼).html" 을 더블클릭해 보세요.

[처음 한 번 — 메인 PC(치료실 스테이션 PC)]

1. zip 파일을 오른쪽 클릭 → [압축 풀기] 로 C:\물리치료기록 같은 곳에 풉니다.
   ※ zip 파일 안에서 바로 exe를 더블클릭하지 마세요 (임시 폴더에서 실행돼 곧 지워짐).

2. 물리치료기록.exe 를 더블클릭합니다.
   - "Windows의 PC 보호" 파란 창이 뜨면: [추가 정보] → [실행]
     (병원에서 직접 만든 프로그램이라 서명이 없어서 뜨는 안내입니다)
   - "Windows 방화벽" 창이 뜨면: [개인 네트워크] 체크 → [액세스 허용]
     (허용해야 태블릿·다른 PC에서 접속할 수 있습니다)

3. 검은 창이 뜨고 크롬(기본 브라우저)에 화면이 자동으로 열립니다.
   검은 창은 서버입니다. 닫지 말고 최소화해 두세요.

4. 앱의 [설정] 탭에서:
   - 처방의·치료사 명단 입력
   - 접속 PIN 지정 (숫자 4~6자리) — 다른 기기가 처음 접속할 때 입력
   - 데이터 폴더를 구글 드라이브 폴더로 변경 (자동 백업)
       [구글 드라이브 폴더 찾기] 버튼 → 나온 경로 확인 → [변경]
       직접 입력 시 예) G:\내 드라이브\물리치료기록
       ※ 웹 브라우저의 구글 드라이브 주소(https://drive.google.com/...)는 넣을 수 없습니다.
       ※ PC에 "Google Drive 데스크톱" 프로그램이 설치·로그인돼 있어야 합니다.
         (설치: https://www.google.com/drive/download/  → 설치 후 탐색기에 G: 드라이브가 생김)
   - 치료 항목 코드를 병원 수가표와 맞춤

5. 컴퓨터를 켤 때 자동 실행되게 하려면:
   Win+R → shell:startup 입력 → 열린 폴더에
   물리치료기록.exe 의 "바로 가기"를 넣습니다. (exe 자체를 옮기지 마세요)


[다른 PC·태블릿]

1. 메인 PC와 같은 와이파이(병원 내부망)에 연결합니다.
2. 앱 [설정] → "메인 PC 연결"에 나오는 주소(예: http://192.168.0.10:8080)를
   크롬 주소창에 입력합니다.
3. PIN을 입력하면 끝. 즐겨찾기 또는 "홈 화면에 추가"를 해 두세요.


[알아둘 것]

- 메인 PC가 꺼지거나 검은 창을 닫으면 다른 기기에서 접속할 수 없습니다.
- 메인 PC의 IP 주소가 바뀌면 태블릿 주소도 바뀝니다.
  바뀌지 않게 하려면 공유기 설정에서 메인 PC에 고정 IP를 지정하세요(전산 담당).
- 데이터 폴더 안의 "기록_YYYY-MM.csv" 파일을 엑셀로 열면 월별 치료 대장을 볼 수 있습니다.
- 이미 실행 중일 때 exe를 다시 누르면 화면만 새로 열립니다.
- 기록·설정은 exe 옆이 아니라 이 PC의 사용자 폴더에 저장됩니다:
    %APPDATA%\물리치료기록   (탐색기 주소창에 그대로 입력하면 열림)
  그래서 exe를 옮기거나 새 버전으로 바꿔도 기록이 그대로 이어집니다.
  (데이터 폴더를 구글 드라이브로 바꿨다면 그 폴더에 저장됩니다)
- 자동 백업: %APPDATA%\물리치료기록\backups 에 날짜별로 30일치 보관됩니다.
  문제가 생기면 원하는 날짜 폴더의 내용을 데이터 폴더에 덮어쓰면 복원됩니다
  (복원 전 프로그램 검은 창을 닫으세요).
- 새 버전으로 바꿀 때: 검은 창 닫기 → 새 exe로 교체 → 다시 실행. 기록·설정은 유지됩니다.
- 포트(8080)를 바꾸려면 %APPDATA%\물리치료기록\config.json 의 "port" 값을 고친 뒤 다시 실행하세요.
